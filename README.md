# datasource-sk-skeleton-merge-01

An engine project of avatars, clothing and animation clips for trying the skeleton merge tool on.

## What it is for

The scenes fit clothing onto avatar bodies by merging their skeletons with the vendored `skeleton_merge_tool` addon. The avatars and clips are the test data, and their licences are under `SK_merge_tool/art/`.

## Build and run

Open `project.godot` in the engine and run the main scene.
